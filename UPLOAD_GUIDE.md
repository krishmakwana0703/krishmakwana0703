# Uploading this GitHub Profile README

1. Download and extract `krish-github-profile.zip`.
2. Open GitHub and create a **public** repository named exactly `krishmakwana0703`.
3. Keep the repository empty when creating it (do not initialize it with a README).
4. Open the new repository and choose **Add file → Upload files**.
5. Upload both:
   - `README.md`
   - the complete `assets` folder (including `profile-banner.svg`)
6. Commit the upload.
7. Open `https://github.com/krishmakwana0703` to view your profile.

Important:
- Keep the `assets` folder beside `README.md` in the repository root.
- The README currently uses only your GitHub profile link. Add your LinkedIn URL or email only after checking that they are correct.
- The featured project link points to your profile because the exact Mini-SIEM repository URL has not been confirmed. Replace it with the project repository URL once you have published that project.
