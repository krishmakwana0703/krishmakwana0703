## 🚀 Featured Project

### Security Log Analyzer and Mini-SIEM

A beginner-friendly Python project that analyzes authentication logs and highlights potentially suspicious login activity.

**What it does**
- Generates sample authentication log data.
- Parses and validates log records.
- Detects repeated failed login attempts and other suspicious patterns.
- Displays security alerts in a Streamlit dashboard.
- Exports generated alerts to a CSV file.

> This project is for learning and demonstration. Its sample data and detection rules are not a replacement for a production SIEM.
